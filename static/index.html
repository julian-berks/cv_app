Welcome

This site started as a small project to practise and test my skills with AWS Bedrock. It lets you ask questions about my CV and get answers drawn from its contents, so you can look up specific skills, technologies or roles without reading it from start to finish.

The back end is a Python application running on AWS Lambda, which handles the calls to Bedrock. I wrote the first version of that code by hand, then used AI to speed up the rest of the development. As I'm not a web developer, I spent some time getting acquainted with Vue 3 before using AI to help build the web front end.

In the interest of transparency, most of the final code you see here was generated by AI, with me directing the work and handling the integration. The answers on this site are generated by AI too.

The code is available in this GitHub repository.
